# Statistical Data Visualization with Matplotlib & Seaborn

Publication-ready statistical plots, customized graphical designs, and visual analytics using Matplotlib and Seaborn.

## 📌 Repository Overview
Showcases the ability to translate complex data distributions and machine learning findings into clear, impactful visual representations.

## 🛠️ Visualization Suite
* **Distribution Plots:** Histograms, KDE plots, boxplots, and violin plots.
* **Relational Plots:** Scatter plots, pair plots, and trend regression lines.
* **Categorical Analytics:** Bar charts, count plots, and heatmaps.
* **Custom Styling:** Tailored color palettes, custom subplots, axis formatting, and publication-ready layouts.

## 🚀 Getting Started

git clone https://github.com/rcr4m0s/data-visualization-matplotlib-seaborn.git
cd data-visualization-matplotlib-seaborn
pip install matplotlib seaborn pandas
